# B5 Universe-thema

🧪 Universe/labwc/themerc, GTK3 donker thema gebaseerd op ingebouwde Adwaita,
GTK3-systeemstandaard en de voorheen ontbrekende mako.conf toegevoegd.
User-configuratie kan GTK-standaarden overrulen. GTK4/libadwaita, Qt, websites
en Wine tekenen hun eigen inhoud; universele kleuraanpassing daarvan is niet bewezen.

Bestands-/instellingscontrole lokaal. Native CSS-/mako-/labwc-laden en visuele
controle vereisen Linux. Claude: venstertitels actief/inactief, sluiten/
minimaliseren/maximaliseren, GTK3 dialoog/bestandsbeheer/focus, lange melding,
kritieke melding en 1024×768/1920×1080/4K testen. Controleer logboeken op fouten.

Bronnen: labwc.github.io/labwc-theme.5.html;
github.com/emersion/mako/blob/master/doc/mako.5.scd;
github.com/GNOME/gtk/blob/gtk-3-24/gtk/theme/Adwaita/gtk-dark.css.
